# 架构决策记录

ADR 用于记录重要、长期、跨模块的决策，包括背景、选项、结论和后果。

以下变化必须新增 ADR：

- 服务边界和数据所有权。
- 新中间件或协议。
- 一致性、幂等和恢复策略。
- 多节点、服务发现和部署方式。
- 数据库 schema 的重大变化。
- 被放弃的重要备选方案。

命名格式：

```text
NNNN-short-title.md
```

每个 ADR 使用以下模板：

```markdown
# ADR-NNNN：标题

- 状态：提议 / 已接受 / 已废弃 / 已替代
- 日期：
- 决策者：
- 关联任务：

## 背景

## 决策

## 备选方案

## 后果

### 正面

### 负面

## 验证方式

## 替代关系
```
